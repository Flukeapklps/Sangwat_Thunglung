# เชื่อมแอปแสงวัฒน์ POS กับ Google Sheet

สคริปต์ `Code.gs` ทำให้แอป**อ่านและเขียน** Google Sheet ได้จริง

- **ออเดอร์:** ทุกออเดอร์ถูกบันทึกลงชีต `ออเดอร์` บรรทัดละ 1 รายการสินค้า
- **สต็อก:** ส่งออเดอร์แล้วสต็อกในชีตสินค้าถูกตัดทันที และสถานะเปลี่ยนเป็น "สินค้าหมด" อัตโนมัติเมื่อเหลือ 0
- **ตารางสรุป:** ชีต `สรุปรายวัน` และ `สรุปตามลูกค้า` ถูกสร้างใหม่ทุกครั้งที่มีออเดอร์เพิ่มหรือถูกลบ เปิดดูในชีตได้เลย
- **สินค้า:** เพิ่ม แก้ไข หรือลบสินค้าในแอป ชีตจะเปลี่ยนตาม
- **หลายเครื่อง:** เปิดแอปจากหลายเครื่องได้ ทุกเครื่องดึงข้อมูลจากชีตเดียวกันทุก 1 นาที

> ถ้ายังใช้สคริปต์เดิม แอปจะอ่านรายการสินค้าจากชีตได้อย่างเดียว ออเดอร์และสต็อกจะไม่ถูกบันทึกลงชีต

## ขั้นตอนติดตั้ง (ทำครั้งเดียว)

1. เปิดไฟล์ Google Sheet ของร้าน แล้วไปที่เมนู **ส่วนขยาย → Apps Script**
2. ในไฟล์ `Code.gs` ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจาก [`Code.gs`](./Code.gs) แทน จากนั้นกด 💾 บันทึก
   - ถ้าอยากเก็บโค้ดเดิมไว้ ให้คัดลอกไปเก็บที่อื่นก่อน
3. ที่แถบด้านบน เลือกฟังก์ชัน **setup** แล้วกด **▶ เรียกใช้**
   - Google จะขอสิทธิ์: กด **ตรวจสอบสิทธิ์ → เลือกบัญชี → ขั้นสูง → ไปที่โปรเจกต์ (ไม่ปลอดภัย) → อนุญาต**
   - หน้านี้ขึ้นเพราะเป็นสคริปต์ที่เราเขียนเอง ไม่ใช่ปัญหา
   - **ไฟล์ว่างก็ใช้ได้:** `setup` จะสร้างชีต `สินค้า`, `ออเดอร์`, `สรุปรายวัน`, `สรุปตามลูกค้า` พร้อมหัวตารางให้ครบ ไม่ต้องพิมพ์หัวตารางเอง
   - รันซ้ำได้ ข้อมูลเดิมไม่หาย
4. กด **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่** แล้วกด ⚙️ เลือก **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
   - กด **ทำให้ใช้งานได้**
5. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
6. ในแอป POS กดปุ่ม **ส** มุมขวาบน → **ตั้งค่า Google Sheet** → วาง URL → กด **บันทึกและเชื่อมต่อ**

เมื่อเชื่อมต่อสำเร็จ สถานะจะขึ้นว่า **"ซิงก์กับ Google Sheet แล้ว"** และข้อมูลสินค้ากับออเดอร์ที่เคยบันทึกในเครื่องนั้นจะถูกส่งขึ้นชีตให้อัตโนมัติ

### อัปเดตสคริปต์เป็นเวอร์ชันใหม่ (เช่น เพิ่มการเก็บรูปสินค้า)

1. วางโค้ด `Code.gs` ใหม่ทับของเดิม แล้วกด 💾 บันทึก
2. เลือกฟังก์ชัน **setup** แล้วกด **▶ เรียกใช้** อีกครั้ง
   - Google จะขอสิทธิ์เพิ่ม (Google Drive สำหรับเก็บรูป) ให้กดอนุญาต
3. ทำขั้นตอน "ถ้าแก้โค้ดสคริปต์ภายหลัง" ด้านล่าง เพื่อให้ลิงก์เดิมใช้โค้ดใหม่

ถ้าแก้โค้ดแล้วไม่ทำขั้นตอนที่ 3 ลิงก์จะยังใช้โค้ดเก่าอยู่

### ถ้าแก้โค้ดสคริปต์ภายหลัง

กด **การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้** → ✏️ แก้ไข → เวอร์ชัน: **เวอร์ชันใหม่** → ทำให้ใช้งานได้

ทำแบบนี้แล้ว URL จะเหมือนเดิม ไม่ต้องตั้งค่าในแอปใหม่

## ชีตที่สคริปต์ใช้

| ชีต | เนื้อหา |
| --- | --- |
| ชีตสินค้า (`สินค้า` / `Products` หรือชีตแรก) | รายการสินค้าและสต็อก สคริปต์จะเพิ่มคอลัมน์ที่ขาด เช่น `id`, `bagStock`, `kgStock`, `status` |
| `ออเดอร์` | บรรทัดละ 1 รายการสินค้า: เลขที่ออเดอร์ วันที่ ลูกค้า สินค้า จำนวน ยอดขาย ต้นทุน กำไร |
| `สรุปรายวัน` | ยอดขาย ต้นทุน กำไร และจำนวนออเดอร์ของแต่ละวัน (สร้างใหม่อัตโนมัติ ไม่ต้องแก้มือ) |
| `สรุปตามลูกค้า` | ยอดซื้อและกำไรของลูกค้าแต่ละคน (สร้างใหม่อัตโนมัติ) |

### หัวตารางชีตสินค้า (สร้างให้อัตโนมัติ)

`id` · `ชื่อสินค้า` · `แบรนด์` · `หมวดหมู่` · `ราคาขายต่อถุง` · `ราคาขายต่อกก.` · `สต็อกถุง` · `สต็อกกก.` · `สถานะ` · `ราคาทุน` · `ค่าคนงาน` · `ค่าบรรทุก` · `ต้นทุนรวม` · `กก.ต่อถุง` · `รูปภาพ`

- เพิ่มสินค้าได้ 2 ทาง: กด "เพิ่มสินค้า" ในแอป (แนะนำ) หรือพิมพ์ลงชีตตรงๆ
- ถ้าพิมพ์ลงชีต ปล่อยช่อง `id` ว่างได้ สคริปต์จะใส่ให้เอง
- ช่อง `สถานะ` คำนวณจากสต็อกอัตโนมัติ
- ชีตเก่าที่ใช้หัวคอลัมน์ภาษาอังกฤษ (`name`, `bagPrice`, `bagStock` …) ก็ใช้ได้เหมือนกัน

## หมายเหตุ

- **เขตเวลา:** ตั้งเป็น **(GMT+07:00) Bangkok** ที่ Apps Script → ⚙️ การตั้งค่าโปรเจกต์ เพื่อให้วันที่ในชีตสรุปถูกต้อง
- **รูปสินค้า:** รูปที่อัปโหลดจากแอปถูกเก็บในโฟลเดอร์ Google Drive ที่ตั้งไว้ใน `IMAGE_FOLDER_ID` (บรรทัดบนๆ ของ `Code.gs`)
  - ชื่อไฟล์เป็น `ชื่อสินค้า - แบรนด์ - วันที่ เวลา` เช่น `ข้าวเหนียว - ตราเสือดำ - 2026-11-05 1430.jpg`
  - ช่อง `รูปภาพ` ในชีตจะมีลิงก์รูป ทุกเครื่องจึงเห็นรูปเดียวกัน
  - เปลี่ยนรูปสินค้า: รูปเก่าในโฟลเดอร์ถูกย้ายไปถังขยะให้อัตโนมัติ (กู้คืนจากถังขยะ Drive ได้ภายใน 30 วัน)
  - บัญชีที่ deploy สคริปต์ต้องมีสิทธิ์ **ผู้แก้ไข** ในโฟลเดอร์นั้น ถ้าเปิดไม่ได้ สคริปต์จะสร้างโฟลเดอร์ `แสงวัฒน์ POS - รูปสินค้า` แทน
  - ไฟล์รูปเปิดให้ "ทุกคนที่มีลิงก์" ดูได้ เพื่อให้แสดงในแอปได้ ถ้าใช้บัญชี Google ขององค์กรที่ห้ามแชร์ไฟล์สาธารณะ รูปอาจไม่แสดงในเครื่องอื่น
- **อินเทอร์เน็ตหลุด:** ออเดอร์ยังบันทึกในเครื่องได้ตามปกติ แล้วถูกส่งขึ้นชีตอัตโนมัติเมื่อกลับมาออนไลน์
- **ความเป็นส่วนตัว:** URL ของเว็บแอปเปิดให้ "ทุกคน" เข้าถึงได้ ใครมีลิงก์ก็อ่านหรือแก้ข้อมูลร้านได้ อย่าแชร์ลิงก์นี้ในที่สาธารณะ
